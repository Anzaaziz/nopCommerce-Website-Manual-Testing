# nopCommerce Website Testing

## Project Overview
nopCommerce is a demo e-commerce web application tested using Manual Testing.

The project focuses on validating major e-commerce functionalities including Registration, Login, Product Search, Product Details, Shopping Cart, Checkout, and Order Placement.

## Application Under Test
- **Application:** nopCommerce Demo Website
- **URL:** https://demo.nopcommerce.com/

## My Role
**Manual Tester**

- Prepared test plan and test cases.
- Executed manual test cases.
- Identified and documented defects.
- Prepared test execution and summary reports.
